# Real-World Case Studies

Each case contains generated source for a native Codex run and a VERAS run.
The model and reasoning effort were matched (`gpt-5.6-sol`, `xhigh`).

The operational datasets and commercial solver license are not redistributed.
No solution file is included when it could expose row-level operational data.
Evaluation summaries and independent audit records are retained so reported
values can be checked against an authorized copy of the data.

- `data_center/`: two-region task placement with a held-out temporal test.
- `power_grid/`: mixed-integer conic planning with independent replay auditing.
