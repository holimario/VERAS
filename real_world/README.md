# Real-World Case Studies

Each case retains the **original historical** native Codex and VERAS sources in
`native_codex/` and `veras/`; these files and their original evaluations are not
retroactively rewritten. The new selected VERAS v0.30-harness transfer sources
and independently checked summaries are in `veras_v030_transfer/`.

The new datacenter result is evaluated only on the visible August 8--9 dates;
the historical native result is from August 10. The new grid run used a
task-specific performance instruction and different agent compute budget from
the historical native run. The historical native numbers are retained, **not**
used as paired controls for new percentage claims. Refer to each case README
and `ARTIFACT_MANIFEST.json` for exact scope and hashes.

Operational datasets, generated row-level assignments, full grid NPZ tensors,
and the commercial solver license are not redistributed. Authorized users can
replay the included source with their own access to the original task packet.
