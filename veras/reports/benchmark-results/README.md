# ORAgentBench Results

This report presents the final VERAS evaluation on all 107 ORAgentBench tasks.

- Open `index.html` through a local HTTP server for the interactive table.
- Machine-readable scores for all tasks are in
  `../../evidence/official-score-summary.json`.
- Retained sanitized trajectories are linked from the same report and stored
  under `tasks/`; no difficulty split has a separate report hierarchy.

The official pass rule is positive feasibility and normalized quality strictly
greater than `0.4`. Incomplete tasks remain in their original denominators.
